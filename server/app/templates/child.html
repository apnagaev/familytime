Пустой лимит — без ограничения, 0 — только учёба. Вне свободного времени компьютер работает только для учёбы. Пустые «с/до» — без ограничения по часам; если «до» меньше «с», окно переходит через полночь.

Сайты, программы и протоколы

Настройки этого ребёнка. Итог = записи вручную + его включённые подписки. Скопировать всё другому ребёнку можно ниже.

По одному на строке, поддомены входят: mos.ru покрывает school.mos.ru. Время на них не считается, в режиме «только учёба» открываются только они и портал.

Закрыты всегда, в любом режиме, вместе с поддоменами. Сайт из этого списка не считается учебным, даже если он есть в учебных.

Имя файла программы, например winword.exe (видно во всплывающей подсказке в статистике). Время в них не считается, после лимита они продолжают работать.

Закрываются сразу после запуска. Сюда — браузеры кроме Chrome, Edge и Яндекса, чтобы учёт сайтов нельзя было обойти.

Ссылки вида telemost://…, которые браузер передаёт программе («Открыть в приложении»). Работают и в режиме «только учёба». Только название протокола: telemost. Саму программу добавьте в учебные.

Лаунчеры игр, мессенджеры в трее. Программы с окном, не попавшие в учебные, закрываются и так.

Простой не считается, только если на экране нет полноэкранного окна: фильм или игра на весь экран считаются всегда. 0 — считать всё время, пока компьютер не заблокирован.

Учётная запись

{% if user.admin %} {% endif %}

Для ребёнка без учётной записи в домене: он входит в портал через Keycloak учётной записью с этой почтой и видит свою статистику. Почта в Keycloak должна быть подтверждена. Доменным детям не нужна: они входят своим логином.

Имена учётных записей на компьютерах вне домена (локальная или учётная запись Microsoft), через запятую. Время под ними идёт в общий лимит этого ребёнка. Как Windows называет учётную запись, видно на странице «Компьютеры».
