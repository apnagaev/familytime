# Дополнительные доверенные центры сертификации

Положите сюда сертификаты центров (`.cer`, `.crt`, `.pem`), которым должны доверять компьютеры,
например корневой и промежуточный сертификаты Минцифры или центр своего домена AD.
`build.ps1` кладёт их в пакет агента, `install.ps1` добавляет их в хранилище компьютера
(корневые — в «Доверенные корневые центры», промежуточные — в «Промежуточные»).

Для компьютеров вне домена удобнее загрузить их в портал: общие настройки → «Доверенные сертификаты».
Тогда их получат и установщик `FamilyTime-setup.cmd`, и агенты 1.4.1+.

Файлы из этой папки в git не попадают (`.gitignore`), кроме этого README.
